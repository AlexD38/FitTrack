# FitTrack

App mobile-first pour suivre tes séances de musculation, ton repos et ta progression.

## Features

- Séances live avec timer de repos
- Journal (historique, édition, templates Push/Pull/Legs…)
- RPE par série, poids libre / poids du corps (0)
- Dashboard : volume, force, muscles, poids, streaks
- Thèmes / palettes, i18n FR/EN, PWA, export JSON

## Stack

React 19 · Vite · Recharts · anime.js · localStorage

## Dev

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
